# 🚌 Bus Route & Schedule Management System

A full-stack web application designed to efficiently manage bus routes, schedules, and user operations with an intuitive admin dashboard and optimized backend performance.

---

## 🚀 Overview

The Bus Route & Schedule Management System is built to simplify public transport management by enabling administrators to create, update, and manage bus routes and schedules dynamically.

It focuses on performance optimization, structured data handling, and a seamless user experience.

---

## ✨ Features

* 🛣️ Dynamic bus route creation and management
* ⏱️ Schedule management for different routes
* 👨‍💼 Admin dashboard for centralized control
* 🔍 Optimized database queries for fast route lookup
* 🔗 REST API integration between frontend and backend
* 📱 Responsive UI for better usability

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```
git clone https://github.com/tharunprasadm2005/bus-route-system.git
cd bus-route-system
```

---

### 2️⃣ Install dependencies

**Frontend**

```
cd client
npm install
npm start
```

**Backend**

```
cd server
npm install
node server.js
```
